# Contract templates

These exist because their absence cost real deals. On 2026-06-26 we wrote to a
partner: "Only thing left now is the agreement." There was no agreement template
anywhere in the company, so nothing was sent, and the deal sat for 34 days.

A check across the whole workspace on 2026-08-11 found **zero files** for every
artifact we had promised a customer:

    invoice template           0 files
    intake questionnaire       0 files
    partnership agreement      0 files
    reseller agreement         0 files
    drupal/angular tips doc    0 files

That is the actual mechanism behind the stalled pipeline: not forgetting, but
having nothing to send. Templates live here so the next promise can be kept the
same day it is made.

## Rules for anything added here
- `{{PLACEHOLDER}}` for every party-specific value, plus a fill sheet at the end.
- Mark invented defaults with `<!-- PROPOSED: ... -->` so a human can check them.
- Never assert a number that is not in a real sent email or a signed document.
- These are drafts, not legal advice. A lawyer reviews before first use.
